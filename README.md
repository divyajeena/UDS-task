Task 1: InputField Component

Overview:
This task implements a flexible input component using React + TailwindCSS, covering common UI requirements like validation states, variants, and sizes.

Setup Instructions:

Clone the repo:
git clone https://github.com/divyajeena/UDS-task.git
cd UDS-task
git checkout my-new-branch

Install dependencies:
npm install

Run dev server:
npm start

Folder Structure:
src/
 ├── App.jsx
 └── components/
      └── ui/
          ├── InputField.jsx        # Reusable InputField component
          └── InputFieldDemo.jsx    # Demo page showing variations
